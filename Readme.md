# Air Quality Data from U.S. Embassies

This repository contains historical air quality data collected from U.S. Embassies and Consulates worldwide.

**Important Note:** As reported by the New York Times on March 4, 2025, the U.S. State Department has discontinued sharing real-time air quality data from its embassies and consulates globally. The original data source on AirNow is no longer available.

[NYT Article: U.S. Quietly Stops Sharing Air Quality Data From Embassies Worldwide](https://www.nytimes.com/2025/03/04/climate/state-department-air-monitoring-embassies.html)

Therefore, the data in this repository represents a historical snapshot and is **no longer being updated** from the original source.

I contacted EPA Public Support, and they kindly provided the historical data contained in this repository.
